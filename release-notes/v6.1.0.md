## What's new
- **14 languages**: Polish, Dutch, Turkish, Russian, Ukrainian, Simplified Chinese, Japanese and Korean join English, French, Spanish, German, Italian and Portuguese. The new translations are machine-assisted: corrections from native speakers are welcome.
- Counted messages use real plural forms, and dates follow the app language.
- Spanish, German, Italian and Portuguese texts that were missing details (power-saving level, SMART state, BIOS memory guide…) are complete.

## Security
- Undoing a fix now re-checks every change before writing it, and only touches the exact settings Dump Finder changed.
- Fixes that need no administrator rights always run in your own account.
- Disk cleanup can no longer be redirected outside the folder being cleaned. It is also skipped if the TEMP variable points somewhere unusual.
- Windows tools (powercfg, sc, nvidia-smi…) always run from the Windows folder, never from the folder next to DumpFinder.exe.
- Web addresses and your Windows account name are removed from what is sent to the AI assistant, over MCP, or saved in exported reports.

## Fixes
- The most recent application crashes no longer disappear when there are many of them.
- A stuck graphics driver or WMI service no longer freezes the scan.
- "Check system integrity (SFC)" no longer deletes crash dumps.
- Applied fixes can still be undone if the administrator window closes early.
- Settings and the AI key survive a crash during saving. A non-standard MCP configuration file is never overwritten.
- Stress test:
  - the right graphics card is tested on laptops with two GPUs;
  - leftover test files are removed after a crash;
  - disk writes are capped;
  - corrected hardware errors are reported as warnings instead of failing the test.
- Closing the window during a stress test now asks first. "Run as administrator" leaves no ghost tray icon.
- Clicking a fix or a scan twice no longer runs it twice. The window fits small screens.
- Detection:
  - blue-screen codes are matched exactly;
  - a too-small fixed page file is reported;
  - the main graphics card is chosen correctly next to an integrated GPU;
  - re-enabling a driver restores its original startup type;
  - Windows Server, Windows 11 25H2 and Windows 10 ESU are recognised.
