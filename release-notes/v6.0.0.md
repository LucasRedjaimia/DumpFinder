First public release of Dump Finder.

## Features
- Crash analysis: blue screens, GPU timeouts and sudden reboots, with the driver involved and its common causes
- Hardware health: BIOS, memory, GPU, SSDs, risky drivers, Windows version
- CPU, memory, GPU and disk stress test with verified results and CPU temperature
- Reversible Windows fixes (TDR, MPO, NVMe SSD HMB, ASPM…)
- Optimise tab: settings, preinstalled apps, startup programs, cleanup
- Optional AI assistant and MCP server
- Interface in 6 languages
- Notification at launch when a new version is available
