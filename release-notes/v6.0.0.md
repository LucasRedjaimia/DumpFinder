Première version publique de Dump Finder.

## Fonctionnalités
- Analyse des crashs : écrans bleus, timeouts GPU, redémarrages brutaux, avec le pilote en cause et ses causes fréquentes
- Santé du matériel : BIOS, mémoire, GPU, SSD, pilotes à risque, version de Windows
- Stress test CPU, mémoire, GPU et disque avec résultats vérifiés et température du CPU
- Correctifs Windows annulables (TDR, MPO, HMB des SSD NVMe, ASPM…)
- Onglet Optimiser : réglages, applications préinstallées, démarrage, nettoyage
- Assistant IA optionnel et serveur MCP
- Interface en 6 langues
- Notification au lancement quand une nouvelle version est disponible
