## What's new
- **Hardware › GPU curve** (NVIDIA cards with MSI Afterburner): see the voltage/frequency curve of your undervolt or overclock next to the stock curve, and how to make it more reliable.
  - The curve **applied right now** is read live from Afterburner (while it runs), along with every saved profile (At startup, Profile 1–5). The profile in use is recognised and marked "applied". If you view a saved profile that differs from what is applied, the page tells you so.
  - Tips taken from the curve itself:
    - a point above the plateau, which makes the card run at a higher voltage than intended;
    - points below the target voltage pushed harder than the target, since they are the ones used for video and the desktop;
    - the plateau's offset over stock;
    - the memory offset.
  - When the graphics driver crashed in the last 30 days (blue screen 0x116 or the NVIDIA driver) while a modified curve is in use, that comes first, with what to do.
  - A **safer suggestion** of the same curve, drawn on the chart, with the points to set in Afterburner's curve editor (Ctrl+F), and a button that opens the GPU stability test.
  - Read-only: Dump Finder never changes your curve or your GPU settings.
