## What's new
- **Everything in your language**: diagnoses, crash explanations, fix messages and stress test results are now shown in all 14 languages, not only English and French. They also switch when you change language (stress results recorded with an older version keep their original language). French, German and Spanish now use a consistent informal tone.
- **Unexpected restarts are told apart** (Kernel-Power 41): a blue screen without a crash dump, a forced shutdown with the power button, or a power cut / hardware fault. Each gets its own explanation.
- **Thermal safety in the stress test**: the test stops by itself if the processor stays at 100 °C or more (graphics card: 95 °C) for 15 seconds, and says what to check (cooling, thermal paste, fan curve).
- **Detection data updated online**: the lists of problematic NVIDIA drivers, DRAM-less SSDs, Windows end-of-support dates and risky drivers are refreshed from GitHub at launch, without waiting for a new version. They are data only, never code, and the refresh follows the switch in **Settings › Updates**.
- **Straight to the right place**: clicking a crash alert opens the matching fix, and "Test the RAM" on the Hardware page opens the RAM stress test.
- **Keyboard and screen readers**:
  - **Ctrl+1…7** open the sections, **F5** runs a new scan, **Esc** closes the crash details;
  - crash rows and guide cards work with Enter / Space;
  - every control has a name for Narrator and NVDA;
  - text contrast meets WCAG AA in both themes, and Windows contrast themes are followed.

## Fixes
- Faster scan on PCs with long event logs or many browser crash dumps: the newest events are read first, within limits, and browser dumps already analysed are not read again.
- Administrator scan: results come back to the app through a checked channel instead of a file in a shared folder, and crash dumps are only copied into a verified folder.
- Resizable BAR is shown as "unknown" when Windows cannot tell, instead of a wrong "off".
- Changing time zone no longer makes every past crash look new.
- Disk health (SMART) is read once for all drives without administrator rights.
- Exported JSON reports stay valid with paths that end in a backslash.
- A damaged crash dump can no longer upset the analysis.
- Long labels in the stress test tiles are no longer cut off. The Home summary buttons no longer show up empty during the first scan.
