## What's new
- **Update from the app**: "Update to x" in the new-version card now downloads the new version, checks it and restarts on it, without going through the browser.
  - Before anything is replaced, the file is checked: it comes from this project's GitHub release, its SHA-256 matches the one GitHub publishes, and it is Dump Finder in exactly the announced version. If anything is off, the current version stays as it is.
  - The new version takes the place of the old one, at the same location, so "Start with Windows" and AI tool (MCP) settings keep working. The old file is removed at the next launch.
  - Not offered while a fix or a stability test is running. If Dump Finder's folder can't be written to, the card says so and offers the download page instead.
  - From this version on, updates install from the app. To get this version, download it once as before.

## Fixes
- The downloaded file is now named after its version (`DumpFinder-6.5.0.exe`). Before, every version was called `DumpFinder.exe`, so browsers saved updates as `DumpFinder (1).exe`, `DumpFinder (2).exe`… and opening `DumpFinder.exe` started an old version again.
- "Start with Windows" no longer moves to another copy of Dump Finder just because you opened it (a second download, for example). It only follows the app when the registered file was moved or deleted.
