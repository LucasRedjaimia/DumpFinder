## Fixes
- **Moving to a new version is cleaner**:
  - When you open Dump Finder and an older version is still running (often in the notification area), the app offers to close it, so only the new version is left.
  - Updating from the app also closes the other windows and the notification-area icon of the previous version before restarting.
  - "Start with Windows" now follows a newer version of Dump Finder, even when the older file is still there (for example in your Downloads folder). Another copy of the same or an older version never takes it over.
- If you are on 6.4 or older, download this version once by hand; from 6.5 on, updates install from the app.
