A fix release for Dump Finder for Mac 0.3.0, with the fixes of the latest Windows versions that also apply to the Mac.

## Fixes
- **Home › stability chart**: the tooltip now sits right above the day you point at and follows it along the line. Before, it stayed where the pointer entered the chart while its text changed. A dotted line and a ring mark the day it describes.
- **Version in the title bar**: shows the full version (0.3.1, not 0.3), so you can see that a fix release was installed.
- **New-version card**: in French, German and other longer languages, the buttons no longer get cut off. "View on GitHub" sits under the release notes, and the buttons move to a second line when they don't fit.
- **Open at login**: another copy of Dump Finder (a second download, a test copy) no longer takes over the login item when you open it. The login item only moves to a copy you open when the copy it points at was moved or deleted, or is an older version.

## Install
1. Unzip and move **Dump Finder.app** to Applications (open at login and the MCP server need it there).
2. The app is not notarized yet, so macOS blocks it the first time: open **System Settings › Privacy & Security**, scroll down and click **Open Anyway**. Only once. (On macOS 14, right-click the app › Open also works.)

Already on 0.3.0? Dump Finder offers this version at launch; your settings, history and change journal are kept.
