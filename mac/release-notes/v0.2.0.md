Dump Finder for Mac now has every section of the Windows app, with the same design, in the same 14 languages (Apple Silicon, macOS 14 or later).

## What's new
- **Home**: 30-day stability score and chart, recommended actions, recent crashes, an HTML report in one click.
- **Crashes**: every kernel panic, unexpected restart and app crash with a plain explanation, the evidence, the suspect extension and the full report; open any .panic / .ips file; 13 common Mac issues with their fix; "Copy for forum".
- **Hardware**: macOS, chip, unified memory, each SSD, battery, temperature, screens and USB / Thunderbolt devices; SIP, Gatekeeper and third-party extensions.
- **Stability test**: processor, unified memory, graphics (Metal) and SSD, each checking its own results. Quick (10 min) or thorough (2 h, overnight); a crash during the test is named at the next launch.
- **Fixes**: GPU acceleration in Chrome / Edge / Brave and Discord, Power Nap, automatic security responses, First Aid. Each one records the value it replaces.
- **Optimize**: Finder and privacy preferences, background agents that start with your session, cleanup of caches and old logs to the Trash, and the "optimizations" worth avoiding.
- **Tools**: macOS diagnostic tools in one click, reports (HTML, JSON, Markdown, text), stability history and the change journal: **every change can be undone**.
- **AI assistant**: "Ask the AI" on any crash with Google Gemini, Claude or Ollama (your key stays in the Keychain), and an MCP server for Claude Desktop, Claude Code, Gemini CLI and Antigravity.
- **Sentinel**: a menu bar icon, a notification when macOS records a kernel panic or a memory shortage, and an optional start at login.
- Update check (Mac releases only), a 3-step introduction, light and dark themes.

## Privacy
Everything is read on your Mac. Nothing leaves it except the update check (GitHub) and, only when you click "Ask the AI", the AI provider you chose. Reports and AI requests have your account name, computer name and web paths removed.

## Known limits
- Not notarized yet: the first time, right-click the app › Open.
- No temperature in °C (macOS reserves it to administrator tools): the stability test uses macOS's thermal state.
- Some Apple setting names in the translations have not been checked by native speakers yet.
